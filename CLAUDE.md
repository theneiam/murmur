# Murmur — notes for Claude Code

Murmur is a menu-bar, push-to-talk dictation app for macOS 14+ / Apple Silicon. Hold a hotkey → record → release → transcribe locally with WhisperKit → insert text at the cursor in the frontmost app. It works end to end as of 2026-09-07 and is in daily use by the owner. Full background is in README.md; this file is the operational cheat-sheet.

## Build & run

```bash
xcodegen generate          # only needed after editing project.yml (regenerates Murmur.xcodeproj, Murmur/Info.plist, Murmur/Murmur.entitlements)
xcodebuild -project Murmur.xcodeproj -scheme Murmur -configuration Debug build 2>&1 | tail -40
open build/DerivedData/Build/Products/Debug/Murmur.app   # or ⌘R in Xcode
log stream --predicate 'subsystem == "com.yevhen.murmur"' --level debug   # app logs
```

Release DMG for personal use: Release `xcodebuild` + `scripts/make-dmg.sh <app> <dmg>`. Signed+notarized distribution: `scripts/release.sh` (needs `TEAM_ID`, `NOTARY_PROFILE`; see README).

Quit any running Murmur before launching a new build — two instances would both install event taps.

## Gotchas (learned the hard way)

- `Murmur/Info.plist` and `Murmur/Murmur.entitlements` are **generated by XcodeGen and git-ignored**. If they go missing, run `xcodegen generate`. Don't hand-edit them; edit `project.yml`.
- **Accessibility permission is bound to the code signature.** If the app is rebuilt with a different signing identity, macOS silently stops trusting it: remove Murmur from System Settings → Privacy & Security → Accessibility and re-add it. Never set an empty `DEVELOPMENT_TEAM` (that forces ad-hoc signing, which changes every build).
- Not sandboxed on purpose: global CGEvent taps and AX writes into other apps require it. Hardened runtime is on; the only entitlement is `audio-input`.
- **The CGEvent tap callback must return in microseconds** (`HotkeyManager.handle`). Anything slow there stalls every keystroke system-wide and the OS disables the tap. `AppState.hotkeyPressed` only flips `phase = .starting` and dispatches the real work async — keep it that way.
- Modifier-only hotkeys match on `flagsChanged` using device-specific left/right bits (`Hotkey.deviceMask`) plus an exact match on the generic modifier bits. Key hotkeys are swallowed (return nil from the tap); modifier hotkeys are never swallowed.
- Murmur's own synthesized ⌘V carries `HotkeyManager.syntheticEventTag` in `eventSourceUserData`; the tap ignores tagged events. Keep the tag on any new synthesized events.
- WhisperKit lives in the renamed package `argmax-oss-swift` (product `WhisperKit`; `import WhisperKit` re-exports `ArgmaxCore`). Do **not** add the `ArgmaxOSS` umbrella product — it pulls in TTSKit, which requires macOS 15.
- WhisperKit model naming trap: OpenAI's large-v3-*turbo* checkpoint is `openai_whisper-large-v3-v20240930[_626MB]`. The `_turbo` suffix on other variants means an encoder compute optimisation, not the turbo model.
- Model files: `~/Library/Application Support/Murmur/Models/models/argmaxinc/whisperkit-coreml/<variant>/`. The tokenizer is fetched from `openai/whisper-*` on the first load of each model and cached under `Models/tokenizers/`; after that everything is offline. First load of a model also triggers CoreML/ANE compilation (seconds for Small, minutes for larger).
- Swift 5.10 language mode, `SWIFT_STRICT_CONCURRENCY=minimal`. Closures handed to AppKit completion handlers are `@Sendable` — use `MainActor.assumeIsolated { }` inside them rather than touching main-actor state directly (see `RecordingIndicator.hide`).
- `UCKeyTranslate` takes plain `Int` lengths in Swift; `UniCharCount` is not exposed.
- Settings are JSON blobs in UserDefaults (`murmur.*` keys). Any struct stored there needs a tolerant `init(from:)` with `decodeIfPresent` (see `PostProcessingOptions`) so adding a field never wipes a user's settings.

## Architecture map

| Area | File | Role |
|---|---|---|
| Coordinator | `App/AppState.swift` | Singleton; push-to-talk state machine (`idle → starting → recording → transcribing → inserting`); wires everything |
| App shell | `App/MurmurApp.swift` | `MenuBarExtra` + `Settings` scenes, `AppDelegate` (accessory policy, onboarding) |
| Hotkey | `Hotkey/Hotkey.swift`, `Hotkey/HotkeyManager.swift` | Model + display names; CGEvent tap, press/release/cancel, hotkey capture for Settings |
| Audio | `Audio/AudioRecorder.swift`, `Audio/AudioDevices.swift` | AVAudioEngine → 16 kHz mono Float32, level meter, max-duration auto-stop; CoreAudio device list |
| Speech | `Transcription/*` | `WhisperModel`/`TranscriptionLanguage` catalog, `TranscriptionEngine` protocol, `WhisperKitEngine` actor (one warm pipeline), `ModelManager` (download/load/status) |
| Insertion | `Insertion/*` | `TextInserter` strategy switch → `AccessibilityInserter` (AX selected-text write + verification) or `PasteboardInserter` (⌘V + clipboard snapshot/restore) |
| Text | `PostProcessing/TextPostProcessor.swift` | Capitalisation, filler stripping, replacement dictionary, trailing space |
| UI | `UI/RecordingIndicator.swift`, `UI/MenuBarView.swift`, `UI/OnboardingView.swift`, `UI/Settings/SettingsView.swift` | Floating non-activating NSPanel; menu; first-run permissions + model download; 5-tab settings |
| Support | `Permissions/`, `Settings/SettingsStore.swift`, `Support/LaunchAtLogin.swift` | Mic/AX permission polling, persisted settings, `SMAppService` |

## Product constraints (don't drift)

- Push-to-talk **only** — no toggle/hands-free mode, no streaming/partial results.
- No network at runtime except user-initiated model download (and the one-time tokenizer fetch). No accounts, telemetry, update checks.
- No Dock icon (`LSUIElement`), no windows that steal focus while dictating; the indicator panel is non-activating.
- Text goes into other apps only; no editor UI of its own.
